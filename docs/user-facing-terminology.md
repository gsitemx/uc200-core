# User-facing Terminology

Este documento define como debe hablar UC200 en su UI y documentacion para usuario final.

## Terminos visibles

- **Extension**: identidad de comunicacion UC200
- **Perfil de llamadas**: reglas base de llamadas para una identidad
- **Metodo de conexion**: forma de enlazar un cliente o telefono
- **Calidad de audio**: perfil de medios
- **Conectividad remota**: ajustes para uso fuera de la LAN
- **Linea SIP / Proveedor SIP**: conexion con operador
- **UC200 Softphone / Web Client**: cliente principal en navegador
- **Softphone externo temporal/pruebas**: opcion de compatibilidad

## Terminos a ocultar para usuario final

- Asterisk
- PJSIP
- AOR
- Endpoint
- Context
- Dialplan
- Transport
- NAT
- Codecs

## Regla de producto

Los terminos tecnicos solo deben verse en modo avanzado para `super-admin` o `engineer`, y siempre con contexto claro de que pertenecen al motor interno.
