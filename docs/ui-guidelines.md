# UI Guidelines

Guia breve para mantener UC200 con una apariencia enterprise compacta y consistente.

## Reglas base

- Evitar apariencia tecnica o de herramienta PBX legacy.
- Priorizar jerarquia clara, densidad alta y acciones frecuentes visibles.
- Usar lenguaje de producto UC200, no lenguaje interno del motor.

## Tablas

- Ningun contenido debe romper el layout.
- Truncar contenido largo con ellipsis.
- Mantener `overflow-x` en contenedores de tabla.
- Acciones alineadas y en una sola linea cuando sea posible.

## Botones

- Tamanos consistentes `sm/xs`.
- Estados hover suaves.
- No usar botones deformados ni con texto desalineado.
- Para estados activos usar clase visual consistente, no estilos inline.

## Softphone / Call Control

- Timer visible.
- Caller info elegante y compacta.
- Controles primarios agrupados.
- Transfer, pickup y park en paneles secundarios cortos.
- Estados visuales claros para mute, hold y llamada activa.
